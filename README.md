# Prusotam Yadav — Portfolio 2026

Personal portfolio of Prusotam Kumar Yadav, full-stack developer building for the web, phones and the Windows desktop.

## Highlights

- WebGL hero: the name is drawn by thousands of particles (three.js + custom shaders) that assemble on load, scatter around the cursor and drift apart on scroll
- Pinned horizontal project gallery with velocity skew, inner parallax and a turbulence ripple on hover
- Preloader, magnetic contact button, custom cursor, scroll-scrubbed statement
- Light and dark themes with no flash on load
- Lenis smooth scrolling synced to GSAP ScrollTrigger

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · GSAP (ScrollTrigger, SplitText) · three.js · Lenis

## Run

```bash
npm install
npm run dev
```

All content (projects, stack, journey, contact) lives in `content/site.ts`.
